================================================================================
                        『マッスルねこ』 コード管理・構成まとめ
================================================================================

【1. 全体アーキテクチャ・依存関係図】

  [Main.cpp] (WinMain: エントリーポイント / DxLib & Direct3D11 初期化 / 60FPSメインループ)
      │
      ├── [CsvManager]          (シングルトン: Statu.csv / Position.csv の解析・座標管理)
      ├── [FontManager]         (シングルトン: 13pt〜96pt のフォントハンドル一括管理)
      ├── [ModelManager]        (シングルトン: .mv1 3Dモデルキャッシュ & プロシージャル代替描画)
      ├── [EffectManager]       (シングルトン: Effekseer 3Dパーティクル管理)
      ├── [CustomEffectManager] (シングルトン: 3Dポリゴンによる炎・湯気・地面えぐり・雷撃・捕獲祝祭)
      │
      └── [GameManager]         (ゲーム全体の進行・シーン遷移・UI描画・デバッグ制御)
              │
              ├── [Camera3D]        (TPS三人称視点カメラ・マウス回転・正面回り込み・壁遮蔽回避)
              │
              └── [ObjectManager3D] (全3Dオブジェクトの更新・描画・衝突解決・捕獲コンボ管理)
                      │
                      ├── [Stage3D]    (ステージ床・壁ポリゴン抽出・マップ別押し戻し・坂道接地)
                      │
                      └── [GameObject3D] (全3Dオブジェクトの抽象基底クラス)
                              ├── [Player3D]      (プレイヤー操作猫・筋トレQTE・飛びつき・スタン攻撃)
                              ├── [Obstacle3D]    (室内の家具・トレーニング器具等の静的障害物)
                              └── [MouseBase3D]   (ネズミ共通基底：巡回AI・逃走AI・スタン・伸縮アニメ)
                                    ├── [NormalMouse3D] (通常ネズミ)
                                    └── [FastMouse3D]   (高速逃走ネズミ)

  ※ 共通ヘッダ群:
     - [Common.h]      : ObjectType 列挙型、MathHelper 数学補助関数群 (Clamp, Lerp, DistanceXZ, LerpAngle)
     - [Config.h]      : 画面解像度(1280x720)、タイトル名「マッスルねこ」、制限時間(120秒)、距離換算定数
     - [ModelConfig.h] : 3Dモデルパス、スケール、回転補正値、マップ種別(MapType::House / NewMap)

--------------------------------------------------------------------------------

【2. 各ファイル・クラスの役割と詳細構成】

■ 1. Main.cpp
  - 役割: アプリケーションの起動、初期化、メインループ、終了解放。
  - 主な処理:
    1) DxLib初期設定 (UTF-8文字コード、1280x720ウィンドウ、タイトル「マッスルねこ」、Direct3D 11)。
    2) シングルトン群 (`CsvManager`, `FontManager`, `ModelManager`, `EffectManager`, `CustomEffectManager`) の `Init()`。
    3) `GameManager` の初期化と `while (ProcessMessage() == 0 && !game.ShouldQuit())` ループの実行。
    4) `GetNowHiPerformanceCount()` による1フレームあたりのCPU処理時間(ms)計測。
    5) 終了時に逆順で全リソースを安全に `Release()`。

■ 2. Common.h / Config.h / ModelConfig.h
  - Common.h:
    - `enum class ObjectType { Player, NormalMouse, FastMouse, Obstacle }`
    - `namespace MathHelper` : `PI`, `DEG_TO_RAD`, `RAD_TO_DEG`, `Clamp()`, `Lerp()`, `DistanceXZ()`, `LerpAngle()`
  - Config.h:
    - 解像度 (`1280 x 720`, `32bit`)、ウィンドウタイトル (`TITLE = "マッスルねこ"`)
    - 猫の基本身長基準 (`CAT_BASE_HEIGHT_UNITS = 104.496f` = `1.8m`、`1m = 58.0533 units`)
    - ネズミ初期出現数 (`NORMAL_MOUSE_COUNT = 5`, `FAST_MOUSE_COUNT = 3`)
    - 制限時間モード設定 (`USE_TIME_LIMIT_MODE = true`, `TIME_LIMIT_SECONDS = 120.0f`)
  - ModelConfig.h:
    - プレイヤーモデル (`cat.mv1`)、バーベルモデル (`Barbell.mv1`)、ネズミモデル (`ネズミ.mv1`) のパス・スケール設定
    - ステージモデル (`MapType::House` = `firstmap.mv1`, `MapType::NewMap` = `newmap.mv1`) のパス・スケール設定

■ 3. CsvManager.h / CsvManager.cpp (シングルトン)
  - 役割: 外部CSVファイル (`Statu.csv`, `Position.csv`) の読み込みとマップ別座標フィルタリング。
  - 主な機能:
    - `LoadStatusCsv()`   : 猫・通常ネズミ・高速ネズミの初速(`base_speed`)、成長率(`speed_growth_per_unit`)、最大速度(`max_speed`)を読み込み。
    - `LoadPositionCsv()` : 猫の初期位置およびネズミのスポーン・巡回ウェイポイント座標リストを読み込み。
    - `ResolveCsvFilePath()` : `Resource/CSV/` と `Source/CSV/` の更新日時を比較し、新しい方を自動採用。

■ 4. FontManager.h / FontManager.cpp (シングルトン)
  - 役割: フォントハンドルの事前生成・一元管理。
  - 管理サイズ:
    - `m_font13`, `m_font16`, `m_font18`, `m_font24`, `m_font36`, `m_font48` (`DX_FONTTYPE_NORMAL`)
    - `m_font60`, `m_font96` (`DX_FONTTYPE_ANTIALIASING_8X8`: タイトルロゴおよびリザルト特大ランク文字用)

■ 5. ModelManager.h / ModelManager.cpp (シングルトン)
  - 役割: 3Dモデル(`.mv1`)の重複読み込み防止キャッシュと、モデル未配置時のプロシージャル代替描画。
  - 主な機能:
    - `LoadModelHandle()`        : パスをキーに `m_modelHandles` でハンドルをキャッシュ管理（テクスチャ自動復旧付き）。
    - `DrawModelIfLoaded()`      : 位置・回転・等方スケールを指定して3Dモデルを描画。
    - `DrawModelWithTransform()` : ローカルピッチ・ロール・3軸非一様スケール行列を合成して描画。
    - `DrawFallbackCat / Mouse / Obstacle / Stage()` : 3Dプリミティブによる代替描画。

■ 6. EffectManager.h / EffectManager.cpp (シングルトン)
  - 役割: Effekseer for DXLib を用いた3Dエフェクト再生管理。
  - 主な機能:
    - タックル突進衝撃波 (`PlayTackleEffect`)、ネズミ捕獲閃光 (`PlayCatchEffect`)、筋トレ成功発光 (`PlayPumpSuccessEffect`)、常駐マッスルオーラ (`UpdateMuscleAura`) の再生・追従制御。

■ 7. CustomEffectManager.h / CustomEffectManager.cpp (シングルトン)
  - 役割: 外部画像に依存しないプロシージャル生成テクスチャと3Dポリゴンを用いた独自エフェクト演出。
  - 主な機能:
    - 筋トレ中の燃焼炎＆火柱（Lvに応じて黄橙→紅蓮→深紅業火へ変化）、Lv.10以上の体から立ち昇る白い湯気。
    - 飛びつき攻撃（Pounce）時の地面えぐり爪痕・3D隆起岩塊・重力バウンド破片・土煙スプラッシュ。
    - スタン攻撃（Tackle）時の電撃ソニックブーム・3Dスピードライン・全身を纏う3D稲妻アーク。
    - ネズミ捕獲時の3D星＆ダイヤ噴水・ゴールド衝撃波リング・放射サンバースト光線・昇天ソウル演出。

■ 8. Camera3D.h / Camera3D.cpp
  - 役割: プレイヤー追従TPSカメラの制御。
  - 主な機能:
    - マウス移動（感度 0.2x〜3.0x 調整可能）および矢印キーによる水平・垂直回転、[F]キーでの正面リセット。
    - 筋トレQTE中 (`isFrontView == true`) に猫の背後から正面アングルへ滑らかに回り込むブレンド補間。
    - `MV1CollCheck_Line` レイキャストによるステージ壁面の遮蔽検知とカメラ手前引き寄せ回避。
    - 捕獲・衝撃時の減衰付きカメラシェイク (`TriggerShake`)。

■ 9. Stage3D.h / Stage3D.cpp
  - 役割: 3Dステージモデルの管理、壁ポリゴン抽出、押し戻し衝突判定、床・坂道の高さ取得。
  - 主な機能:
    - `BuildHouseCollision()` / `BuildNewMapCollision()` : マップ1(`firstmap.mv1`)とマップ2(`newmap.mv1`)それぞれのメッシュ構造に合わせて垂直壁ポリゴン(`WallPolygon`)を抽出。
    - `ResolveWallCollision()` : 三角形上の最近接点(`ClosestPointOnTriangle`)を用いた最大4回反復の滑らかな壁押し戻し。
    - `GetGroundHeight()`      : レイキャストにより床・スロープの正確なY座標を取得し、壁上への誤ワープを防止。

■ 10. GameObject3D.h / Obstacle3D.h / Obstacle3D.cpp
  - `GameObject3D` : 全3Dオブジェクト共通の座標(`m_pos`)、向き(`m_rotY`)、半径(`m_radius`)、生存フラグ(`m_isAlive`)を持つ抽象基底クラス。
  - `Obstacle3D`   : 室内の家具・器具を表し、AABB対円の水平押し出し判定 (`ResolveCollision`) を実装。

■ 11. Mouse3D.h / Mouse3D.cpp
  - 役割: 捕獲ターゲットであるネズミ（`NormalMouse3D` / `FastMouse3D`）のAIとアニメーション。
  - 主な機能:
    - パトロール巡回AI (`ChooseNewPatrolTarget`, `UpdateWanderMovement`) とプレイヤー接近時の逃走AI (`UpdateFleeMovement`)。
    - 仲間が捕まるごとに移動速度が上昇する動的難易度調整 (`m_speedBonus`)。
    - プレイヤーのスタン攻撃を受けた際の気絶状態 (`ApplyStun`) と3D頭上ピヨピヨ星演出 (`DrawStunEffect`)。
    - ホッピング跳躍・ロール揺れ・前傾・Squash & Stretch・スタン横倒し痙攣を計算する `GetAnimTransform()`。

■ 12. Player3D.h / Player3D.cpp
  - 役割: プレイヤーキャラクター「マッスルねこ」のアクション・成長・アニメーション制御。
  - 主な機能:
    - カメラの水平向きを基準としたWASD移動と、レベルに応じた速度上昇 (`CalculateSpeedForRep`)・体格巨大化。
    - [SPACE]長押しによる筋トレQTEゲージ（成功で +1 Rep & 15秒維持タイマーリセット、失敗で5秒間筋肉痛停止）。
    - 15秒間筋トレまたは捕獲がない場合に -3 Rep されるパンプ減衰システム。
    - Lv.4 (4 Rep) 以上で解放される2大アクション:
      1) 飛びつき (`Pounce`: 左クリック / SHIFT) : 前方のネズミへ緩やかにホーミングしながら放物線跳躍して捕獲。
      2) スタン攻撃 (`Tackle`: 右クリック / E)   : 電撃を纏って超高速突進し、接触したネズミを長時間スタンさせる（壁に激突すると猫自身が1.5秒スタン）。
    - Mixamoボーンフレーム (`LeftHand`, `RightHand`) のワールド座標から変換行列を構築し、スクワット中に両手でバーベル (`Barbell.mv1`) を保持する `DrawBarbell()`。

■ 13. ObjectManager3D.h / ObjectManager3D.cpp
  - 役割: ステージ内の全オブジェクトの一括管理、衝突解決、捕獲コンボ演出。
  - 主な機能:
    - プレイヤー・ネズミ群・障害物・ステージの更新と描画順序制御。
    - 壁・障害物との押し出し判定および床のない領域（崖・マップ外）への落下を防止する壁沿いスライディング処理。
    - ネズミ捕獲判定、約3.5秒以内の連続捕獲によるコンボラッシュ集計、ヒットストップ、3D座標から浮かび上がるコミック風ポップアップ描画。

■ 14. GameManager.h / GameManager.cpp
  - 役割: シーン遷移 (`Title` / `Playing` / `GameClear`)、ポーズ制御、2D UI描画、F1デバッグ機能。
  - 主な機能:
    - タイトル画面 (`DrawTitleScreen`, `DrawTitle3DScene`):
      3D空間でスクワットと腕立て伏せを交互に行う猫の周囲をカメラが旋回し、「マッスルねこ」の立体カートゥーンロゴ、48種類以上のボディビル掛け声吹き出し、ステージ選択UIを描画。
    - プレイ中HUD & ポーズ画面 (`Draw`, `UpdatePause`, `DrawPauseModal`):
      左上ステータスバッジ（レベル・維持ゲージ・残りネズミ数・120秒制限時間タイマー）、右下操作ガイド、ESCポーズメニュー（リトライ・タイトル・マウス感度スライダー）。
    - リザルト画面 (`DrawGameClearScreen`):
      クリア/タイムアップ時にまず筋トレする猫へカメラがズームイン（75フレーム）し、背景で猫がスクワットし続ける状態でアメコミ風S/A/B/Cランクスタンプ、クリア統計、報酬ボーナス（ダンベル・猫缶・スター）を表示。
    - F1デバッグオーバーレイ (`DrawDebug3DOverlay`, `DrawDebug2DOverlay`):
      猫の身長1.8mを基準とした10m×10m×10m目測ワイヤーフレームキューブ、身長物差し、壁ポリゴン可視化、2Dミニマップレーダー、各種デバッグチート機能（[1]〜[8]キー）。
