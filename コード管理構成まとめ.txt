================================================================================
  MuscleCat 3D - 全マネージャー・管理システム構成 完全リファレンス
================================================================================

本ドキュメントは、MuscleCat 3D プロジェクト内の「すべての管理系クラス（Manager）」
および「各種オブジェクト・設定管理ファイル」が、どこで・何を・どのように管理して
いるかを網羅的にまとめた技術仕様書です。

================================================================================
1. システム全体の管理階層（アーキテクチャ図）
================================================================================

  [Main.cpp (WinMain)]
     │
     ├─【グローバル・シングルトン管理系（アプリ起動〜終了まで常駐）】
     │   ├─ 1. CsvManager    : CSVデータ管理（Statu.csv 速度 / Position.csv 座標）
     │   ├─ 2. FontManager   : フォントハンドル事前生成・サイズ別キャッシュ管理
     │   ├─ 3. ModelManager  : 3Dモデル(.mv1)ハンドルキャッシュ＆代替プリミティブ描画管理
     │   └─ 4. EffectManager : Effekseer / 3Dパーティクル演出の読込・再生・追従管理
     │
     └─【ゲーム進行・空間管理系（GameManager が統括）】
          └─ 5. GameManager  : シーン状態（タイトル/プレイ中/ポーズ/クリア）・UI・F1デバッグ統括
               ├─ 6. Camera3D        : 三人称視点(TPS)カメラ追従・壁めり込み防止・マウス感度管理
               └─ 7. ObjectManager3D : 3D空間内の全オブジェクト更新・当たり判定・捕獲管理
                    ├─ 8. Stage3D    : ステージ3Dモデル＆マップ1/マップ2別当たり判定・接地管理
                    ├─ 9. Player3D   : プレイヤー(猫)の移動・筋トレ成長・スキル・アニメ管理
                    ├─ 10. Mouse3D   : ネズミAI（通常巡回 / 高速逃走 / スタン / 速度成長）管理
                    └─ 11. Obstacle3D: 家具・障害物の3D配置および円柱押し出し判定管理

2. シングルトン管理系クラス（4大マネージャー）の詳細
================================================================================

--------------------------------------------------------------------------------
【1】CsvManager（Source/CsvManager.h, Source/CsvManager.cpp）
--------------------------------------------------------------------------------
■ 設計パターン : シングルトン (`CsvManager::GetInstance()`)
■ 管理対象     : 外部CSVファイルによるゲームバランス（速度）とマップ配置座標の一元管理
■ 参照ファイル :
  ・優先パス   : `Resource/CSV/Statu.csv`, `Resource/CSV/Position.csv`
  ・予備パス   : `CSV元ファイル/Statu.csv`, `CSV元ファイル/Position.csv`
■ 主な保持データ（メンバ変数）:
  ・`m_catStatus`           : 猫の初期速度(`baseSpeed`=4.00)、1Lv成長量(`speedGrowthPerUnit`=0.10)、上限(`maxSpeed`=5.50)
  ・`m_mouseStatus`         : ネズミの初期速度(4.20)、1匹捕獲ごとの成長量(0.05)、上限(4.70)
  ・`m_fastMouseStatus`     : 高速ネズミ用ステータス
  ・`m_catPositions`        : Position.csv の `Cat` 行から読み込んだ初期スポーン座標リスト
  ・`m_mousePositions`      : Position.csv の `Mouse` 行から読み込んだ Pos1〜Pos8 座標リスト
  ・`m_catPositionsHouse` / `m_mousePositionsHouse` : マップ1（House）用の室内座標リスト
■ 主要メソッドと処理内容 :
  ・`Init()` / `ReloadAll()`
      起動時およびゲーム開始時(`GameManager::StartGame`)に呼ばれ、CSVを再読込して即時反映する。
  ・`LoadStatusCsv(primaryPath, fallbackPath)`
      `Statu.csv` をパースし、Role(`Cat` / `Mouse`)ごとの速度パラメータを更新する。
  ・`LoadPositionCsv(primaryPath, fallbackPath)`
      `Position.csv` の `X:Y:Z` 形式セル(`ParseVectorCell`)をパースして3D座標リストを構築する。
  ・`GetCatPositionsForMap(mapType)` / `GetMousePositionsForMap(mapType)`
      現在選択中のマップ（`MapType::House` または `MapType::NewMap`）に対応した座標配列を返す。

--------------------------------------------------------------------------------
【2】ModelManager（Source/ModelManager.h, Source/ModelManager.cpp）
--------------------------------------------------------------------------------
■ 設計パターン : シングルトン (`ModelManager::GetInstance()`)
■ 管理対象     : 3Dモデルファイル（`.mv1`）の重複ロード防止キャッシュ管理、および
                 モデル未配置時のプロシージャル3Dプリミティブ代替描画管理
■ 主な保持データ（メンバ変数）:
  ・`m_modelHandles` (`std::unordered_map<std::string, int>`)
      ファイルパスをキー、DxLibの `MV1LoadModel` ハンドルを値とするキャッシュ辞書。
■ 主要メソッドと処理内容 :
  ・`Init()`
      主要3Dモデル（猫・バーベル・ネズミ・ステージ・家具）を事前ロードしてキャッシュに登録。
  ・`LoadModelHandle(path)`
      未ロードなら `MV1LoadModel` で読み込んで辞書に登録し、既読ならキャッシュ済みハンドルを返す。
      （`Player3D` や `Stage3D` はこのベースハンドルから `MV1DuplicateModel` で複製して使用する）
  ・`DrawModelIfLoaded(path, pos, rotY, scale, rotX, rotZ)`
      指定パスのモデルに座標・回転・スケールを適用して `MV1DrawModel` で描画する。
  ・`DrawFallbackCat()` / `DrawFallbackNormalMouse()` / `DrawFallbackFastMouse()` /
    `DrawFallbackObstacle()` / `DrawFallbackStage()`
      万が一 `.mv1` ファイルが存在しない環境でもゲームが動作するよう、球やカプセル等の
      3Dプリミティブを組み合わせてキャラクターやステージを描画するセーフティネット関数群。
  ・`Release()`
      終了時に全キャッシュモデルハンドルを `MV1DeleteModel` で一括解放する。

--------------------------------------------------------------------------------
【3】EffectManager（Source/EffectManager.h, Source/EffectManager.cpp）
--------------------------------------------------------------------------------
■ 設計パターン : シングルトン (`EffectManager::GetInstance()`)
■ 管理対象     : Effekseer 3DエフェクトおよびDxLib 3Dパーティクル演出の生成・追従・ON/OFF管理
■ 主な保持データ（メンバ変数）:
  ・`m_tackleResHandle`      : タックル突進エフェクトのリソースハンドル
  ・`m_pumpSuccessResHandle` : 筋トレ成功時エフェクトのリソースハンドル
  ・`m_muscleAuraResHandle`  : パンプアップ中マッスルオーラのリソースハンドル
  ・`m_activeAuraHandle`     : 現在再生中のオーラ追従用ハンドル
  ・`m_effectEnabled`        : エフェクト表示ON/OFFフラグ（デバッグ `[6]` キーで切替可能）
■ 主要メソッドと処理内容 :
  ・`Init()` / `Release()`
      Effekseer初期化および `.efkefc` エフェクトリソースの読み込み・解放。
  ・`Update()` / `SyncCamera()` / `Draw3D()`
      毎フレームのEffekseer更新、DxLibカメラ行列との同期、3D空間へのエフェクト描画。
  ・`PlayTackleEffect(pos, dir)`
      猫が右クリック（またはEキー）でタックルを発動した瞬間の衝撃エフェクト再生。
  ・`PlayPumpSuccessEffect(pos, repCount)`
      筋トレで1レップ達成した瞬間の発光エフェクト再生。
  ・`UpdateMuscleAura(pos, isActive, repCount)` / `StopMuscleAura()`
      猫の現在位置・筋トレレベルに連動して黄金マッスルオーラを追従再生・停止する。
  ・`SetEffectEnabled()` / `ToggleEffectEnabled()`
      F1デバッグメニューの `[6] エフェクト表示` ON/OFF切替を管理。

--------------------------------------------------------------------------------
【4】FontManager（Source/FontManager.h, Source/FontManager.cpp）
--------------------------------------------------------------------------------
■ 設計パターン : シングルトン (`FontManager::GetInstance()`)
■ 管理対象     : UI・HUD・デバッグ文字列描画用のフォントハンドル事前生成・キャッシュ管理
                 （毎フレーム `SetFontSize` を呼ぶことによる描画負荷・カクつきを防止）
■ 主な保持データ（メンバ変数）:
  ・`m_font13` (13px) : デバッグ詳細数値、ミニマップピン番号、ガイド補足用
  ・`m_font16` (16px) : HUDラベル、デバッグ見出し、操作パネル用
  ・`m_font18` (18px) : メニュー項目、サブタイトル、中サイズUI用
  ・`m_font24` (24px) : スコア、レベル表示、ボタン文字用
  ・`m_font36` (36px) : 画面見出し、カウント表示用
  ・`m_font48` (48px) : タイトル・リザルト大見出し用
  ・`m_font60` (60px) : メインタイトルロゴ・クリア演出用
■ 主要メソッドと処理内容 :
  ・`Init()`    : アンチエイリアス・エッジ付きフォント（`DX_FONTTYPE_ANTIALIASING_EDGE_8X8`）を全サイズ生成。
  ・`Release()` : `DeleteFontToHandle` で全フォントハンドルを解放。
  ・`GetFont13()` 〜 `GetFont60()` : 各サイズのフォントハンドルを取得。

【5】GameManager（Source/GameManager.h, Source/GameManager.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : ゲーム全体のステートマシン（状態遷移）、画面UI、入力分岐、F1統合デバッグ管理
■ 管理しているゲーム状態 (`enum class GameState`) :
  ・`Title`       : タイトル画面（ステージ1/2切替、ゲーム開始、遊び方モーダル、猫演出）
  ・`Playing`     : 本編プレイ中（TPSカメラ操作、筋トレ・捕獲アクション、ポーズ、F1デバッグ）
  ・`StageClear`  : 全ネズミ捕獲時のステージクリア演出
  ・`AllClear`    : 完全クリア画面（クリアタイム計測・ランク評価・リトライ/タイトル帰還）
■ 主な保持データ（メンバ変数）:
  ・`m_objManager`      : `ObjectManager3D` インスタンス（全3Dオブジェクトとステージを保持）
  ・`m_camera`          : `Camera3D` インスタンス（TPSカメラ管理）
  ・`m_selectedMap`     : 現在選択中のステージ（`MapType::House` または `MapType::NewMap`）
  ・`m_isPaused`        : ポーズ画面の開閉状態と選択項目インデックス (`m_pauseMenuItem`)
  ・`m_cheatEnabled`    : `[F1]` デバッグ＆チートオーバーレイの有効フラグ
  ・`m_debugCubeMode`   : `[7]` キーで切り替える10m×10m×10m目測キューブ表示モード (0〜3)
  ・`m_debugWideCamera` : `[8]` キーで切り替える10m全体俯瞰カメラモード
■ 主要メソッドと処理内容 :
  ・`Init()`
      ステージ初期化と `SetupTitle()` の呼び出し。
  ・`SwitchSelectedMap(newMap)`
      タイトル画面での左右キー・クリックによるステージ切替管理。
      - マップ1 (`House`)  : 室内床面 `(0.0f, 5.0f, 0.0f)` に猫を配置
      - マップ2 (`NewMap`) : マップ中央の円柱台座上面 `(0.0f, 200.0f, 0.0f)` に猫を配置
  ・`SetupTitle()`
      タイトル画面の初期化、Lv.6マッチョ猫の生成と円柱/床への配置。
  ・`StartGame()`
      CSV再読込 (`CsvManager::ReloadAll`)、ステージ読込、プレイヤー生成、
      `Position.csv` のスポーン候補点への通常ネズミ(3匹)・高速ネズミ(2匹)の接地配置。
  ・`Update()`
      状態別の毎フレーム更新、ポーズ画面でのマウス感度変更、F1デバッグ中の `[1]`〜`[8]` ショートカット管理。
  ・`DrawDebug3DOverlay()`
      `[F1]` ON時の3Dデバッグ描画（10mグリッド、10m×10m×10mワイヤーフレーム立方体、
      身長1.8m物差し、攻撃範囲リング、Pos1〜8ピン、壁当たり判定ワイヤーフレーム）。
  ・`DrawDebug2DOverlay()`
      `[F1]` ON時の2Dデバッグパネル描画（猫の速度u/f・m/s・km/h、ネズミ個体別速度と距離、
      右上2Dトップダウン・ミニマップ＆10mレーダー、チート操作一覧）。

【6】ObjectManager3D（Source/ObjectManager3D.h, Source/ObjectManager3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : プレイ空間内の全動的オブジェクト（猫・ネズミ・障害物）のライフサイクルと衝突解決
■ 主な保持データ（メンバ変数）:
  ・`m_stage`          : `Stage3D` インスタンス（現在のマップモデルと壁・床当たり判定）
  ・`m_player`         : `std::shared_ptr<Player3D>`（プレイヤー猫）
  ・`m_objects`        : `std::vector<std::shared_ptr<GameObject3D>>`（生存中の全ネズミリスト）
  ・`m_obstacles`      : `std::vector<std::shared_ptr<Obstacle3D>>`（配置された家具・障害物リスト）
  ・`m_caughtCount`    : 捕獲したネズミの累計数
  ・`m_isTimeFrozen`   : デバッグ `[4]` キーによるネズミ時間停止フラグ
■ 主要メソッドと処理内容 :
  ・`InitStage(mapType)` / `LoadStage(mapType)`
      `m_stage` に対して指定マップの読み込み・コリジョン構築を実行させる。
  ・`SpawnNormalMouse()` / `SpawnFastMouse()`
      `CsvManager` から現在マップの `Pos1〜Pos8` を取得し、`m_stage.GetGroundHeight` で確実に
      床面高さを合わせた上で通常ネズミ・高速ネズミを追加スポーンさせる。
  ・`ApplyMouseSpeedBonus()`
      ネズミが1匹捕まるごとに、残りの生存ネズミ全員へ `caughtCount * speedGrowthPerUnit` の
      速度ボーナス（`Statu.csv` 準拠）を再計算して適用する。
  ・`Update(camera)`
      1. プレイヤーの移動・スキル更新 (`UpdateWithCamera`)
      2. 全ネズミのAI移動更新（`m_isTimeFrozen` が OFF のとき）
      3. 壁・床・障害物との物理押し出し解決 (`CheckObstacleAndStageCollisions`)
      4. 猫とネズミの捕獲・タックル気絶判定 (`CheckCollisions`)
      5. 捕獲されたネズミ (`!IsAlive()`) のリスト削除
  ・`CheckObstacleAndStageCollisions()`
      - 猫と壁ポリゴンの押し戻し (`m_stage.ResolveWallCollision`)
      - タックル中に壁へ衝突した場合、猫自身に90フレーム（1.5秒）の気絶スタンを付与
      - 猫・ネズミの床・坂道接地追従 (`m_stage.GetGroundHeight`) と、床のない領域への落下防止スライド処理
      - ネズミが壁に当たった際の反射ベクトル通知 (`mouse->OnWallCollision`)

【7】Stage3D（Source/Stage3D.h, Source/Stage3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : 3Dステージモデル（`.mv1`）の描画と、「マップ1 / マップ2 完全分離型」の壁・床・境界コリジョン管理
■ 主な保持データ（メンバ変数）:
  ・共通設定 : `m_mapType`, `m_modelPath`, `m_scale`, `m_modelHandle`, `m_hasCollision`
  ・マップ1 (`House`: `firstmap.mv1`) 専用データ :
      - `m_houseWallPolygons` : マップ1の垂直壁ポリゴン配列
      - `m_houseMinBounds` / `m_houseMaxBounds` : マップ1の外周AABB境界
  ・マップ2 (`NewMap`: `newmap.mv1`) 専用データ :
      - `m_newMapWallPolygons` : マップ2のガードレール壁・部屋外壁ポリゴン配列
      - `m_newMapMinBounds` / `m_newMapMaxBounds` : マップ2の外周AABB境界
■ 主要メソッドと処理内容 :
  ・`LoadStage(mapType)`
      前モデルの破棄・両ポリゴン配列クリア後、モデルを複製して `m_mapType` に応じて
      `BuildHouseCollision()` または `BuildNewMapCollision()` を呼び出す。
  ・`BuildHouseCollision()` 【マップ1専用】
      - 全高35未満の床メッシュ (`Mesh[2]`) および不要な原点デフォルトキューブ (`Mesh[10]: pCube55`) を除外・非表示化。
      - 高さ35以上・上端Y>=30・`|normal.y| < 0.35` の垂直壁ポリゴンのみを `m_houseWallPolygons` に構築。
  ・`BuildNewMapCollision()` 【マップ2専用】
      - 原点床下の不要キューブ (`polyMinY < -20.0f`) を除外。
      - 通路の側壁ガードレール（高さ20）および各部屋外壁（高さ200）を `m_newMapWallPolygons` に構築。
  ・`ResolveWallCollision(outPos, radius, outPushNormal)`
      `m_mapType` に応じて `ResolveHouseWallCollision()` または `ResolveNewMapWallCollision()` に分岐し、
      Ericsonの三角形最近接点アルゴリズム (`ClosestPointOnTriangle`) による最大4回反復の壁押し戻しを実行。
  ・`GetGroundHeight(pos, outGroundY, outGroundNormal)`
      - マップ1 (`GetHouseGroundHeight`)  : `Y = 30.0f 〜 -30.0f` の範囲で室内床面 (`Y ≈ 5.0f`) のみを検出。
      - マップ2 (`GetNewMapGroundHeight`) : 足元付近 (`pos.y + 120.0f 〜 pos.y - 180.0f`) の坂道・床面を優先検出し、
        セーフティネットとして上空からのレイキャストも備える。
  ・`ClampToBounds(outPos, radius)`
      `ClampToHouseBounds()` / `ClampToNewMapBounds()` によりマップ別の外周境界内に座標を制限。

--------------------------------------------------------------------------------
【8】Camera3D（Source/Camera3D.h, Source/Camera3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : 三人称視点（TPS）カメラの座標補間、マウス・キーボード視点回転、壁めり込み防止、感度管理
■ 主な保持データ（メンバ変数）:
  ・`m_targetPos` / `m_currentPos` : 注視点およびカメラ座標（スムーズ補間後）
  ・`m_angleH` / `m_angleV`        : 水平回転角・垂直仰俯角（ラジアン）
  ・`m_distance` / `m_height`      : 猫からの基準距離(220.0f)・基準高さ(140.0f)
  ・`m_mouseSensitivityScale`      : マウス視点感度倍率（0.2x 〜 3.0x、デフォルト 1.0x）
■ 主要メソッドと処理内容 :
  ・`Init(initialTargetPos, initialAngleH)`
      ゲーム開始時に猫の背後へカメラを初期配置し、マウスカーソルを画面中央へリセット。
  ・`Update(...)`
      1. マウス移動量（または矢印キー）に `m_mouseSensitivityScale` を掛けて水平・垂直アングルを更新。
      2. 画面端でマウスが止まらないよう毎フレーム画面中央へカーソルを再センタリング。
      3. ステージモデルに対してレイキャストを行い、壁の裏にカメラが隠れる場合は壁の手前へ距離を寄せる。
  ・`Apply()`
      DxLibの `SetCameraPositionAndTarget_UpVecY` に計算済みカメラ座標と注視点を反映。
  ・`SetMouseSensitivity(scale)` / `AdjustMouseSensitivity(delta)`
      プレイ中の `[-]`/`[+]` キーやポーズ画面スライダーからのマウス感度変更を管理（リトライ時も維持）。

【10】Player3D（Source/Player3D.h, Source/Player3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : プレイヤー（マッスルキャット）の移動・筋トレQTE・パンプアップ成長・攻撃スキル・3Dアニメ管理
■ 主な管理要素 :
  1. **移動スピード管理 (`CalculateSpeedForRep`)**
     - `CsvManager::GetCatStatus()` の `baseSpeed`(4.00), `speedGrowthPerUnit`(0.10), `maxSpeed`(5.50) を参照し、
       現在の筋トレ回数 (`m_repCount`, 上限Lv.15) に応じた移動速度をリアルタイム算出。
  2. **筋トレ（SPACE長押し）＆パンプアップ管理**
     - SPACEキー押下中にバーベルスクワットを行い、レップ数 (`m_repCount`) を加算。
     - レップ数に応じて猫の3Dモデルスケールと身長（基準 `1.80m = 104.5u` から最大約 `2.7m`）が拡大。
     - 15秒間 (`PUMP_DECAY_FRAMES = 900`) 筋トレしないと徐々にパンプがしぼむ減衰タイマー管理。
  3. **攻撃スキル管理（Lv.4 / 4 Rep 以上で解放）**
     - **左クリック：飛びつき捕獲 (`Pounce`)**
       前方のネズミを自動ホーミング補間しながら高速ジャンプ突進し、拡大した捕獲半径で一気に捕まえる。
     - **右クリック（またはEキー）：肉弾タックル (`Tackle`)**
       前方へ猛突進し、接触したネズミを気絶（スタン）させる。ただし壁に激突すると猫自身が1.5秒スタンする。
  4. **3Dモデル＆ボーンアタッチ管理 (`InitModel`, `UpdateAnimation`, `DrawBarbell`)**
     - `cat.mv1` の6種のアニメーション（Run / Attack / Squat / Idol / Push / Soreness）のブレンド再生。
     - 猫の両手ボーンフレーム（`m_lHandFrame`, `m_rHandFrame`）のワールド座標を取得し、筋トレ中に
       `Barbell.mv1`（バーベルモデル）を両手の位置・角度・スケールに完全同期させて描画。

【11】MouseBase3D / NormalMouse3D / FastMouse3D（Source/Mouse3D.h, Source/Mouse3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : ネズミAIの巡回・逃走アルゴリズム、壁反射、スタン状態、捕獲数に応じた速度成長管理
■ クラス構成と管理内容 :
  ・**`MouseBase3D`（ネズミ共通基底クラス）**
      - `ChooseNewPatrolTarget()` : `CsvManager` から現在マップの `Pos1〜Pos8` を取得し、現在地から一定距離以上
        離れた別の部屋・通路ポイントを次の巡回目標 (`m_targetWaypoint`) に選択する。
      - `UpdateWanderMovement()`  : 目標ウェイポイントへ向けて滑らかに向きを補間しながら移動。
      - `UpdateFleeMovement()`    : 猫が近づいた際、猫と反対方向へ逃走ベクトルを計算。
      - `OnWallCollision(normal)` : 壁や境界にぶつかった際、壁の法線ベクトルに沿って反射・スライドし、
        スタックしないよう新しい巡回目標を再選択する。
      - `ApplyStun(frames)`       : 猫のタックルを受けた際の気絶タイマー管理と頭上ピヨピヨ星エフェクト描画。
  ・**`NormalMouse3D`（通常ネズミ）**
      - 基本はウェイポイント間を巡回し、猫が至近距離に来たときのみ回避行動をとる。
  ・**`FastMouse3D`（高速逃走ネズミ）**
      - 猫が感知距離 (`160.0f` ≒ 2.76m) 以内に入ると即座にパニック汗漫符を出して高速逃走する。

【12】Obstacle3D（Source/Obstacle3D.h, Source/Obstacle3D.cpp）
--------------------------------------------------------------------------------
■ 管理対象 : ステージ内に配置される家具・障害物（キッチン・冷蔵庫・テーブル・テレビ等）の描画と押し出し判定
■ 主要メソッド :
  ・`Draw3D()`           : `ModelManager` を通じて家具3Dモデルを描画。
  ・`ResolveCollision()` : 直方体AABBとキャラクター円柱半径の交差を判定し、最短軸方向へ押し出す。
